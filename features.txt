### 1. Download & Install Tools Utama

#### A. Rust Toolchain (`rustup`)
1. Buka situs resmi: **[rustup.rs](https://rustup.rs/)**
2. Download file **`rustup-init.exe`** (pilih versi 64-bit).
3. Jalankan `rustup-init.exe`.
4. Saat muncul pilihan di terminal:
   - Pilih opsi **1** (`Proceed with installation (default)`), lalu tekan **Enter**.

#### B. C++ Build Tools (Syarat Wajib Rust di Windows)
Rust di Windows membutuhkan *C++ Linker* dari Microsoft untuk mengkompilasi program:
- Jika Anda **sudah memiliki Visual Studio** (2019/2022):
  - Buka *Visual Studio Installer*, pastikan centang workload **"Desktop development with C++"**.
